# W3Schools Clothing Store Clone

A responsive clothing store website recreated from the original W3Schools Clothing Store template using HTML and CSS only.

## Features

- Sidebar navigation with clothing categories
- Expandable Jeans dropdown menu
- Promotional hero banner
- Product grid with eight clothing product cards
- Product labels, including New and Sale
- Newsletter subscription section
- Contact form and store information
- Responsive layout for mobile and desktop
- CSS hover effects and transitions

## Technologies

- HTML5
- CSS3

## Project Structure

- `index.html` – Website structure and content
- `style.css` – Website styling and responsive layout
- `images/` – Clothing and banner photographs

## Run Locally

Open `index.html` in your web browser.
