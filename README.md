# DENIM & THREAD

DENIM & THREAD is a responsive clothing store website featuring jeans, jackets, and T-shirts.

## Features
- Clothing product grid with eight product images
- Hero banner with a shop collection link
- Sidebar navigation
- Newsletter and contact sections
- Responsive layout for mobile and desktop
- CSS hover effects

## Technologies
- HTML5
- CSS3

## Run Locally
Open `index.html` in your web browser.
